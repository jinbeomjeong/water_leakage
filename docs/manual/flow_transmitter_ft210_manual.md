## 단자 배치 (6쪽)

| 왼쪽 열 | 오른쪽 열 |
|---|---|
| AO+ | POW1 |
| AO− | POW2 |
| PO+ | RL1_C |
| PO− | RL1_NO |
| COM_A | RL2_C |
| COM_B | RL2_NO |

6쪽 그림에는 단자 번호가 없다. 9~10쪽 결선도의 번호(RL1 3·4, RL2 5·6, AO 7·8, PO 9·10)로 보면 오른쪽 열이 1~6번, 왼쪽 열이 7~12번이다. 이 경우 COM_A는 11번, COM_B는 12번이 되지만 매뉴얼에 직접 적혀 있지는 않다.

- 통신 옵션 제품은 릴레이 단자가 빠지고 메뉴의 릴레이 설정도 없다 (6, 11, 13쪽).
- 통신 옵션이 없는 제품에는 COMM SET 메뉴가 없다 (11, 15쪽).

## Modbus RTU 요약 (18쪽)

| No | 항목 | 레지스터 | 데이터 형식 | 읽기/쓰기 |
|---|---|---|---|---|
| 1 | Volume Total | 40001, 40002 | 4바이트 IEEE float | 읽기 |
| 2 | Volume Acc Total | 40003, 40004 | 4바이트 IEEE float | 읽기 |
| 3 | Volume Rate (순시유량) | 40005, 40006 | 4바이트 IEEE float | 읽기 |

- 읽기는 Function Code 03 (Holding Register), 초기화는 06 (Preset Single Register)이다.
- Device Address는 18쪽 표에 01~32로 적혀 있고, COMM ID 설정 범위는 15쪽에 0~50으로 적혀 있다.
- 단위는 Flow Set의 Total_Unit과 Time Base 설정을 따르는 것으로 보인다 (매뉴얼에 명시 없음).

## 매뉴얼에 없는 내용

2026-11-23 장비에서 확인한 값은 [FT-210 통신 설정값](../system_info/sensor/ft210_flow_meter_settings.md)에 있다.

| 항목 | 장비에서 확인한 값 |
|---|---|
| RS-485 데이터 비트, 패리티, 스톱 비트 | 8N1 |
| 레지스터 주소 | 표준 Modbus 방식, 40001이 `0x0000` (40005는 `0x0004`) |
| "4321 Swapped FP"의 바이트 순서 | 뒤집지 않은 빅 엔디안 |
| COM_A, COM_B의 단자 번호 | 미확인 |
| 통신 응답 대기 시간, 종단 저항 | 미확인 |
