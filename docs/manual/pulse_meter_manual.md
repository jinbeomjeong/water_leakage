형식은 `MP5 ❶ - ❷ ❸`이다. 일부 조합은 지원하지 않으므로 오토닉스 웹사이트에서 확인한다.

| 코드 | 항목 | 값 |
|---|---|---|
| ❶ S | 크기 | DIN W 48 × H 48 mm |
| ❶ Y | 크기 | DIN W 72 × H 36 mm |
| ❶ W | 크기 | DIN W 96 × H 48 mm |
| ❷ 2 | 전원 전압 | 24 VAC 50/60 Hz, 24~48 VDC |
| ❷ 4 | 전원 전압 | 100~240 VAC 50/60 Hz |

| 시리즈 | ❸ 출력 코드 | 메인(비교값) 출력 | 보조(표시값) 출력 |

| MP5Y | N | 표시 전용 | - |

## MP5Y 단자 (p.2)

MP5Y 외의 단자 배치는 원본을 확인한다. MP5S는 p.2, MP5W는 p.3에 있다.

### 전원 / 입력 단자대

| 단자 | 신호 |
|---|---|
| 1 | INA |
| 2 | INB |
| 3 | HOLD / RESET (단자 4와 접점으로 연결) |
| 4 | 0 V |
| 5 | +12 V (외부 공급 전원) |
| 6, 7 | SOURCE (제품 전원) |

HOLD / RESET 단자는 F1~F12에서 HOLD, F13~F16에서 RESET으로 동작한다.

### 출력 코드 5: RS485 커넥터

| 단자 | 신호 |
|---|---|
| 7 | RS485 A (+) |
| 8 | RS485 B (-) |

- 커넥터: 히로세 HIF3BA-10PA-2.54DS, 적용 소켓 HIF3BA-10D-2.54R
- 별매 I/O 케이블: CO20-HP□-□ (오토닉스)

α는 프리스케일 값이다.

### F1 표시 단위별 α (p.5)

| 표시값 | 단위 | α |
|---|---|---|
| 주파수 | Hz | 1 |
| 주파수 | kHz | 0.001 |
| 회전수 | rps | 1 |
| 회전수 | rpm (출하값) | 60 |
| 속도 | mm/sec | 1,000 L |
| 속도 | cm/sec | 100 L |
| 속도 | m/sec | 1 L |
| 속도 | m/min | 60 L |
| 속도 | km/hour | 3.6 L |

L은 1회전당 이동 거리(m)다. 물체가 여러 개이면 α = 60L / N이다.

### F13 적산 동작 (p.7)

- 입력 A의 펄스 수를 계수한다.
- 입력 B는 Enable 입력이다. ON이면 계수와 표시값이 정지하고, OFF이면 다시 계수한다.
- RESET 입력이 ON이면 계수값이 0으로 초기화된다.

## 출력 모드 (p.5)

메인 출력이 표시 전용인 모델은 출력 모드를 지원하지 않는다.

| 모드 | 동작 요약 | 비교값 조건 |
|---|---|---|
| S (Standard) | HH, H는 표시값 이상, L, LL은 표시값 이하에서 출력 | 크기 순서 무관 |
| H (High) | HH, H, L, LL 모두 표시값 이상에서 출력 | 크기 순서 무관 |
| L (Low) | HH, H, L, LL 모두 표시값 이하에서 출력 | 크기 순서 무관 |
| B (Block) | 비교값 구간별로 하나씩 출력 | LL < L < H < HH |
| I (One-shot) | 0.3 sec 고정 출력, GO와 히스테리시스 없음 | 크기 순서 무관 |
| F (Deflection) | 저장한 설정값에서 H, L 편차를 넘으면 출력, HH, GO, LL 없음 | 편차 범위 0.0001~99999 |

## 파라미터 색인 (p.4)

- `통신 No`는 [통신 매뉴얼 색인](pulse_meter_com.md)에서 이름으로 대응시킨 번호다. 제품 매뉴얼에 적힌 값이 아니다.
- `[비교]`는 비교값 출력 모델, `[PV]`는 PV 전송 출력 모델, `[485]`는 RS485 통신 출력 모델에만 해당한다.
- 설정 범위가 입력 동작 모드에 따라 달라지는 비교값과 FS-H, FS-L은 [범위 표](#비교값과-pv-전송-출력의-설정-범위)를 참고한다.

## 키 조작 (p.4)

| 조작 | 동작 |
|---|---|
| RUN에서 [MODE] | 파라미터 0그룹 진입 |
| RUN에서 [MODE] 2초 | 파라미터 그룹 진입 |
| 파라미터 그룹에서 [MODE] 3초 | RUN으로 복귀 |

| [◀] | 고정 항목 확인, 설정값 변경 시 자리 이동 |

60초 이상 키 입력이 없으면 운전 모드로 돌아간다.

## 기능 (p.7)

| 기능 | 내용 | 관련 파라미터 |
|---|---|---|
| 히스테리시스 | 비교값 부근에서 출력이 자주 바뀌는 것을 막는다. | P1-5 |
| 감시 지연: 비교 출력 제한 | 전원 투입 후 초기 L, LL 비교 출력을 내지 않는다. | P1-6 = F.DEFY |
| 감시 지연: 기동 보상 타이머 | 설정 시간 동안 출력을 내지 않는다. | P1-6 = STAR.T, P1-7 |
| Auto-zero 시간 | 설정 시간 안에 입력이 없으면 표시값을 0으로 만든다. 가장 늦은 입력 간격보다 조금 길게 설정한다. | P1-8, P1-9 |
| 데이터 뱅크 | 비교값과 프리스케일을 2종류로 저장한다. MP5W의 단자 3, 5를 개방하면 뱅크 1, 단락하면 뱅크 2를 쓴다. | P2-1 |
| 프리스케일 | 입력 펄스에 X × 10^Y를 곱해 원하는 단위로 표시한다. 예: α = 15이면 X = 1.5000, Y = 1 | P2-10~P2-13 |

## 통신 매뉴얼 색인과의 관계

[통신 매뉴얼 색인](pulse_meter_com.md)에서 "실기 확인이 필요한 내용"으로 둔 항목 일부가 이 매뉴얼에 적혀 있다.

| 통신 매뉴얼 색인의 항목 | 이 매뉴얼의 내용 | 쪽 |
|---|---|---|
| 데이터 비트 수 | 8 bit 고정 | 3 |
| 400001~400008과 400105~400112의 관계 | 파라미터 0그룹과 2그룹의 비교값은 서로 연동된다. | 4 |
| DISpT 코드값의 단위 | sec. 설정값은 OFF, 0.05, 0.5, 1, 2, 4, 8 | 3, 4 |

두 매뉴얼에서 값이 다른 항목은 다음과 같다.

| 항목 | 제품 매뉴얼 | 통신 매뉴얼 |
|---|---|---|
| HYS 설정 범위 | 0000~9999 (p.4) | 1~9999 (p.23) |
| RSwT 설정 범위 | 통신 속도별로 다름 (p.4) | 5~99 ms (p.25) |
| 파라미터 초기화 | P3-11 mRST 있음 (p.4) | 레지스터 없음 |

## 매뉴얼에서 일관되지 않은 부분

- F16 설명은 표시 주기를 P2-13, 입력 B 설정값을 P2-14로 적었지만, 파라미터 표에서는 P2-14, P2-15다 (p.4, 7).
- 내충격(오동작)은 100 m/s²인데 괄호 안 환산값이 30 G로, 300 m/s²와 같다 (p.3).
- PV 전송 응답 시간의 기준이 표시 주기 0.2초인데, 표시 주기 설정값에 0.2초가 없다 (p.3).
