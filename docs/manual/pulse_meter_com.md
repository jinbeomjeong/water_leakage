## Function Code (p.12~18)

| Func | 이름 | 대상 | 쪽 |
|---|---|---|---|
| 01 (0x01) | Read Coil Status | 0X | 12 |
| 02 (0x02) | Read Input Status | 1X | 13 |
| 03 (0x03) | Read Holding Registers | 4X | 14 |
| 04 (0x04) | Read Input Registers | 3X | 15 |
| 05 (0x05) | Force Single Coil (0xFF00 = ON, 0x0000 = OFF) | 0X | 16 |
| 06 (0x06) | Preset Single Register | 4X | 17 |
| 16 (0x10) | Preset Multiple Registers | 4X | 18 |

- 주소와 데이터는 High 바이트, CRC-16은 Low 바이트가 먼저다 (p.12).
- PLC, 그래픽 패널 등 외부 기기와 연결할 때는 Func 16보다 Func 06을 권장한다. PC 로더에서 파라미터를 미리 지정해 Download 하는 경우는 예외다 (p.19).

## 구현 시 주의 사항

### 매뉴얼에 적힌 내용

- COmW 출하값이 `0: DISA`이므로, 통신으로 쓰려면 먼저 쓰기를 허가해야 할 수 있다. 쓰기 금지 상태에서는 예외 코드 04가 온다 (p.20, 25).
- 2워드 파라미터는 Func 03/16만 지원한다. p.19의 Func 06 권장 사항은 이 파라미터에 적용할 수 없다 (p.23~25).

### 매뉴얼에 없어 실측으로 확인한 내용

장비에서 측정한 결과이며, 자세한 내용은 [펄스미터 통신 설정값](../system/sensor/pulse_meter_com_settings.md)에 있다.

- PV의 워드 순서: `301002`가 하위 워드, `301003`이 상위 워드다.
- PV 계산: 원시 정수를 `10^DOT`으로 나눈다. 전면 표시값과는 아직 비교하지 않았다.

### 매뉴얼에 없어 실기 확인이 필요한 내용

- 음수 표현 방식
- PV에 프리스케일이 이미 적용된 값인지 여부
- 데이터 비트 수: 설정 항목이 없다 (p.25). 8비트로 통신에 성공했다.
- 400001~400008과 400105~400112의 관계: 같은 이름의 비교값이 두 곳에 있다 (p.23, 24).
- DISpT 코드값의 단위

### 매뉴얼에서 일관되지 않은 부분

- Func 05의 프레임은 설명되어 있지만, 매핑 표의 코일은 모두 읽기 전용(R)이다 (p.16, 21).
- 300122~300124와 301007 이후 주소는 매핑 표에 없다 (p.21~22).
