# 펄스미터 통신 설정값

장비에서 직접 읽은 값이다.

- 읽은 시각: 2026-11-04 17:33
- 읽은 방법: Modbus RTU Func 03, 시작 주소 `0x009B`, 레지스터 7개
- 레지스터 설명: [통신 매뉴얼 색인](../../manual/pulse_meter_com.md)

## 연결 정보

| 항목 | 값 | 출처 |
|---|---|---|
| 장비 모델 | `MP5Y-25` | 사용자 확인 |
| 통신으로 읽은 모델명 | `MP5Y-45` (실제 모델과 다름) | 레지스터 `300105~300114` |
| PC 포트 | COM3 (FTDI USB 시리얼 어댑터, `0403:6001`) | PC 포트 정보 |
| 프로토콜 | Modbus RTU | 매뉴얼 p.5 |
| 데이터 비트 | 8 | 매뉴얼에 없음, 이 값으로 통신 성공 |

## 통신 설정

| 파라미터 | No(Address) | 레지스터 값 | 의미 | 출하값 |
|---|---|---|---|---|
| ADDR 통신 국번 | 400156 (009B) | 1 | 1 | 1 |
| BPS 통신 속도 | 400157 (009C) | 2 | 9600 bps | 2 (9600 bps) |
| PRTY 패리티 | 400158 (009D) | 0 | NONE | 0 (NONE) |
| STP 스톱 비트 | 400159 (009E) | 1 | 2비트 | 1 (2비트) |
| RSwT 응답 대기 시간 | 400160 (009F) | 5 | 5 ms | 20 ms |
| COmW 통신 쓰기 | 400161 (00A0) | 1 | ENA (허가) | 0 (DISA) |
| LOC 잠금 | 400162 (00A1) | 0 | OFF | 0 (OFF) |

출하값과 다른 항목은 RSwT와 COmW다.

## PV 해석 방법

매뉴얼에 없는 내용이며, 2026-11-04에 이 장비에서 측정해 확인했다.

- 워드 순서: `301002`가 하위 워드, `301003`이 상위 워드다.
- 계산: 원시값 = (상위 워드 << 16) | 하위 워드, PV = 원시값 / 10^DOT (`301004`)

| 근거 | 값 |
|---|---|
| 읽은 레지스터 (`301002`, `301003`, `301004`) | 103~106, 0, 2 |
| 위 방법으로 계산한 PV | 1.03~1.06 (예상값 약 1.0) |
| 워드 순서를 반대로 해석한 값 | 약 67502 |

아직 확인하지 못한 항목은 다음과 같다.

- 전면 표시값과의 비교
- 음수 표현 방식: 코드는 32비트 2의 보수로 가정한다.
- 상위 워드에 값이 들어가는 큰 값의 실측

## 접속 예시

```python
from pymodbus import FramerType
from pymodbus.client import ModbusSerialClient

client = ModbusSerialClient(port='COM3', framer=FramerType.RTU, baudrate=9600, parity='N', stopbits=2, bytesize=8)
```

요청할 때 국번은 `device_id=1`로 지정한다.

## 주의 사항

- COmW가 ENA이므로 통신으로 파라미터를 바꿀 수 있다. 쓰기 명령을 보낼 때 주의한다.
- COM 번호는 PC나 USB 포트에 따라 달라질 수 있다.
- 모델명 레지스터 값이 실제 모델과 다르므로, 코드에서 `MP5Y-25`와 일치하는지 검사하면 실패한다. 차이의 원인은 확인되지 않았다.
