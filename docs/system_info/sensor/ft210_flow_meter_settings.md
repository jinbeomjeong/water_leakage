# FT-210 유량계 통신 설정값

플로우닉스 KOT-EX 방폭형 터빈유량계의 표시·변환기 FT-210을 보드(RAK4631 + RAK5802)에서 RS-485 Modbus RTU로 읽는 설정이다.

- 확인한 날짜: 2026-11-23
- 매뉴얼 색인: [FT-210 사용자 매뉴얼 색인](../../manual/flow_transmitter_ft210_manual.md)
- 펌웨어: `src/board/header/flow_meter.h`, `src/board/src/flow_meter.cpp`

## 통신 설정

| 항목 | 값 | 출처 |
|---|---|---|
| 프로토콜 | Modbus RTU | 장비 COMM SET → PROTOCOL (사용자 설정) |
| 통신 속도 | 9600 bps | 장비 COMM SET → BAUD RATE (사용자 설정) |
| 국번 | 1 | 장비 COMM SET → COMM ID (사용자 설정) |
| 데이터 비트, 패리티, 스톱 비트 | 8N1 | 매뉴얼에 없음. 장비에서 시험 (8N2, 8E1은 깨진 바이트) |

## 순시유량 읽기

| 항목 | 값 | 출처 |
|---|---|---|
| Function Code | 03 (Read Holding Registers) | 매뉴얼 p.18 |
| 레지스터 | 40005, 40006 (Volume Rate) | 매뉴얼 p.18 |
| 요청 시작 주소 | `0x0004`, 레지스터 2개 | 장비에서 시험 |
| 데이터 형식 | 4바이트 IEEE 754 float, 빅 엔디안 (받은 순서 그대로) | 장비에서 시험 |

요청과 응답 예 (유량 0일 때):

```
요청 01 03 00 04 00 02 85 CA
응답 01 03 04 00 00 00 00 FA 33
```

### 매뉴얼과 다른 점

| 항목 | 매뉴얼 | 장비 |
|---|---|---|
| 40005의 주소 | p.18 Reset 예시에서 40003을 `00 03`으로 써서 `0x0005`로 보였다 | `0x0004`. 표준 Modbus처럼 40001이 `0x0000`이다 |
| `0x0005`로 읽을 때 | - | 바이트 수를 4로 적고 데이터는 2바이트만 보낸다 (`01 03 04 00 00 58 45`). 레지스터 맵 끝을 넘어서는 것으로 보인다 |
| 바이트 순서 | "4321 Swapped FP" | 빅 엔디안 그대로다. `3FD47AE1`은 이 순서로 1.66, 네 바이트를 뒤집으면 −2.9e20이다 |

## 확인 결과 (2026-11-23)

| 항목 | 값 |
|---|---|
| 보드가 읽은 값 | 1.37~1.49 (1초 주기) |
| 전면 표시 | 1.37 |
| ChirpStack 디코딩 | `008b` → `{"flow_status": "normal", "flow_lpm": 1.39}` |

## 유량 단위

장비의 순시유량 단위를 L/min(LPM)으로 설정했다 (2026-11-23, 사용자 설정). 업링크와 코덱은 이 값을 LPM으로 다룬다.

## 아직 확인하지 못한 것

- RS-485 단자 번호: 배선은 COM_A(+), COM_B(−)에 했다. 매뉴얼에는 번호가 없다.
- 종단 저항: 탁상 시험이라 쓰지 않았다.
- 응답 시간: 펌웨어는 200 ms까지 기다린다. 실제 응답 시간은 재지 않았다.
